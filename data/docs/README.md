# 把待检索的文档放在这里

支持子目录，脚本会递归扫描 *.pdf：

```
data/docs/
├── 可行性研究报告/可行性研究报告.pdf
├── 软件需求规格说明书/软件需求规格说明书.pdf
├── 系统概要设计说明书/系统概要设计说明书.pdf
└── 系统详细设计文档/系统详细设计文档.pdf
```

按上面这套布局放置，README 里的对照数字（214 页 / 15.6 万字 / 三种策略块数）可直接复现。

任意 PDF 都行，只是换了文档后切块统计会不同。

## 为什么不把 PDF 放进仓库

- 这些是项目内部文档，不适合公开
- PDF 体积大，不适合进 git

.gitignore 已排除 data/docs/**/*.pdf，所以放进去也不会被误提交。
